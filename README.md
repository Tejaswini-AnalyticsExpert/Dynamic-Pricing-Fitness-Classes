# Dynamic Pricing & Demand Forecasting for Fitness Classes

## Project Overview

This project analyzes fitness class booking data to develop:
- demand forecasting models
- price elasticity analysis
- high-demand class identification
- dynamic pricing strategies

The objective is to optimize:
- revenue per class
- overall company revenue
- operational efficiency

---

## Business Problem

Static pricing strategies often fail to respond to changing customer demand patterns.

This project uses data analytics and forecasting techniques to:
- identify booking trends
- forecast future demand
- analyze pricing sensitivity
- implement dynamic pricing strategies

---

- Python

## Project Workflow

### 1. Data Cleaning & Preprocessing
- handled missing values
- removed duplicates
- standardized column names
- corrected data types
- created datetime features

### 2. Exploratory Data Analysis (EDA)
- booking trend analysis
- seasonal analysis
- high-demand class analysis
- correlation analysis

### 3. Price Elasticity Modeling
- regression model development
- pricing sensitivity analysis
- model validation

### 4. Demand Forecasting
- time series forecasting
- ARIMA model implementation
- future demand prediction

### 5. High-Demand Analysis
- peak demand identification
- occupancy analysis
- booking pattern analysis

### 6. Dynamic Pricing Algorithm
- occupancy-based pricing
- revenue optimization simulation
- pricing strategy implementation

## Key Insights

- Certain classes consistently generate higher booking demand.
- Booking demand varies across days and months.
- Dynamic pricing can improve revenue potential.
- Forecasting supports operational planning and pricing optimization.
